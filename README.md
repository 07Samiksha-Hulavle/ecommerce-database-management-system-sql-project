# 🛒 SQL E-Commerce Database Project

# 📌 Project Overview
This project is a beginner-friendly E-Commerce Database Management System built using SQL Server. It is designed to practice and strengthen core SQL concepts through a real-world business scenario involving customers, products, and orders.

The project demonstrates how relational databases work and includes multiple SQL operations used in database management and data analysis.

# 🛠 Technologies Used
* SQL Server
* SQL Server Management Studio (SSMS)

# 📂 Database Structure
# Customers Table
Stores customer information:
* Customer ID
* Name
* City

# Products Table
Stores product details:
* Product ID
* Product Name
* Price

# Orders Table
Stores purchase records:
* Order ID
* Customer ID
* Product ID
* Quantity
